## Regra Critica da Agenda

O usuario reforcou que nada deve ser extremamente proibido em agendamentos.

Regra esperada:

- Se atingir uma regra/conflito, o sistema deve avisar.
- O usuario deve conseguir confirmar.
- Tecnicamente deve ser possivel agendar mesmo acima da regra.

Backend implementado:

- Se houver conflito e `confirmarConflito` nao for `true`, retorna HTTP `409` com aviso.
- Para salvar mesmo assim, reenviar o mesmo payload com `confirmarConflito: true`.
- Neuromodulacao acima de 2 no mesmo horario/profissional/unidade segue o mesmo fluxo.


Comando:

```powershell
cd C:\dev\sistema-clinica-backend
.\scripts\importar-pacientes.ps1 -Arquivo "C:\Users\guilherme.ferreira\Downloads\Acess_no_excel_gabriel_eh_foda.xlsx"
```

Regras do import:

- Coluna `Codigo`/`C?digo` do Excel vira `pacientes.id` no banco.
- Esse mesmo codigo tambem vira `numeroPaciente`.
- Campo `Celular` recebe nono digito quando vier DDD + 8 digitos.
- Campo `Telefone` apenas normaliza; nao adiciona nono digito.
- Telefones concatenados podem ser separados.
